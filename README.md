# Sandia Community High School Website

## Project Overview

A responsive public-facing website for Sandia Community High School, located in Foya Statutory District, Lofa County, Liberia.

**School Motto:** Excellence in Action, Success in Sight.

## Website Pages

- Home
- About Us
- Academics
- TVET Programs
- Student Life
- News & Events
- Gallery
- Contact

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub (version control and publication workflow)

## Running the Website Locally

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Use the Live Server extension to launch the website in a browser.
4. Navigate through the pages and test the interactive features.

## Project Status

The initial public-facing website has been developed and tested locally. The contact form currently demonstrates frontend behavior only; it does not yet send or store messages.
