# Sandia Community High School Website

## Project Overview

A responsive, public-facing website for Sandia Community High School, located in Foya Statutory District, Lofa County, Liberia.

**School Motto:** Excellence in Action, Success in Sight.

## Website Pages

- Home
- About Us
- Academics
- TVET Programs
- Student Life
- News & Events
- Gallery
- Contact

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub for version control and publication
- GitHub Pages for website hosting
- FormSubmit for contact form submissions

## Running the Website Locally

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Launch the website using the Live Server extension.
4. Navigate through the pages and test the relevant features.
5. Check the browser console if you encounter errors.

## Project Status

The website is published on GitHub Pages and has been tested locally and on the live site. The homepage, navigation, mobile menu, and contact form have been verified.

The contact form is configured with FormSubmit and has been reported to submit inquiries successfully. Email delivery depends on the form service and its configuration.

## Maintenance and Development

- Make website changes in the Git-connected project folder.
- Test changes locally before publishing.
- Review Git status and inspect changes before committing.
- Push verified commits to GitHub and check the live website afterward.
- Maintain separate backups of the project.
- Monitor performance, accessibility, mobile responsiveness, security, and content accuracy.
