## 1. Project Overview

The project involves designing, developing, deploying, testing, and maintaining a modern, responsive website for Sandia Community High School.

The website provides information about the school, its academic programmes, TVET programmes, student life, news and events, and contact information.

**School motto:** Excellence in Action, Success in Sight.

**Design colours:** Maroon and white.

## 2. Technology Stack

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages hosting
- FormSubmit contact form service
- Google Search Console
- Google PageSpeed Insights

Development and maintenance are performed using Visual Studio Code on Windows 11.
